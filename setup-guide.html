1. GPIO Pinout (40-Pin Header)

Der Pi 5 hat einen 40-poligen Stiftleistenanschluss. Pin 1 ist an der Ecke mit der weißen Markierung auf der Platine (Richtung SD-Karte).

Power (3.3V / 5V) GND (Masse) GPIO (frei nutzbar) I2C SPI UART

Für Taster: Nimm irgendeinen grünen Pin (GPIO) + einen grauen Pin (GND). Empfehlung: GPIO 17 (Pin 11) + GND (Pin 9).

Für den OLED (I2C): 3.3V (Pin 1), GND (Pin 6), SDA (Pin 3 = GPIO 2), SCL (Pin 5 = GPIO 3).

2. Taster anschließen

Verkabelung

Ein einfacher Taster zwischen GPIO-Pin und GND reicht. Das GPIO-Modul aktiviert den internen Pull-Up-Widerstand, d.h. der Eingang ist im Ruhezustand HIGH und wird beim Drücken auf LOW gezogen.

Wichtig: Niemals 5V an GPIO! Die Pins vertragen maximal 3.3V. Zum Pull-Up reichen die internen Widerstände.

Schaltung

Empfehlung: 4-Pin-Taster (Mini-Printtaste), aber auch 2-Pin-Taster funktionieren.

Pin-Nummerierung verstehen

Verwirrend: Pi kennt zwei Nummerierungen.

Das Companion-Modul arbeitet mit BCM/GPIO-Nummern — nicht mit Pin-Nummern.

Vermeiden:
  • GPIO 0, 1 — Reserviert (EEPROM)
  • GPIO 2, 3 — I2C (OLED)
  • GPIO 14, 15 — UART (seriell)

3. GPIO-Modul in Companion konfigurieren

  1. Öffne die Companion Web-UI (Tab links).
  2. Gehe zu Connections → + Add connection.
  3. Suche nach raspberry und wähle "Raspberry Pi foundation · RPi GPIO (Dev)".
  4. Vergib einen Namen (z.B. gpio) und öffne die Konfiguration.
  5. Scrolle zum gewünschten Pin (z.B. GPIO 17):
    • ✅ Use GPIO pin anhaken
    • Set as IN/OUT: IN
    • Trigger type: FALLING (Taster zieht auf GND)
    • ✅ Enable debouncing, Debounce time: 50 ms
    • Optional: Invert values anhaken, dann ist "gedrückt" = 1
  6. Speichern. Der Pin erscheint jetzt als Variable in Companion unter $(gpio:gpio17).

4. Beispiel: Taster schaltet ATEM Aux-Quelle

Ziel: Beim Drücken eines angeschlossenen Tasters soll der ATEM Aux 1 zwischen Input 1 und Input 2 toggeln.

  1. ATEM-Verbindung anlegen
    Connections → + Add → suche atem → "Blackmagic Design · ATEM" → IP der ATEM-Switcher eintragen.
  2. Variable des GPIO-Pins nutzen
    Nach Schritt 3 liefert das Modul z.B. $(gpio:gpio17) → 0 oder 1.
  3. Trigger erstellen
    Linke Seitenleiste → Triggers → + neuer Trigger:
    • Name: Aux1 Toggle
    • Event: On variable change → Variable gpio:gpio17
    • Condition: gpio:gpio17 = 1 (bei steigender Flanke / Tastendruck)
  4. Custom Variable für Toggle-Zustand
    Variables → Custom → neue Variable aux1_state, Startwert 1.
  5. Actions im Trigger:
    1. Action: Set custom variable → aux1_state = $(internal:custom_aux1_state) == 1 ? 2 : 1
    2. Action: ATEM → Set Aux source → Aux 1 → Source: $(internal:custom_aux1_state)
  6. Speichern. Taster drücken → Aux springt zwischen Input 1 und 2.
Alternative ohne Toggle: Lege zwei Taster an (GPIO 17 + GPIO 27) und je einen Trigger pro Pin, der direkt Aux auf Input 1 bzw. 2 setzt. Das ist einfacher und verlässlicher.
