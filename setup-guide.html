GPIO Pinout (40-Pin Header)

Der Pi 5 hat einen 40-poligen Stiftleistenanschluss. Pin 1 ist an der Ecke mit der weißen Markierung auf der Platine (Richtung SD-Karte).

Power (3.3V / 5V) GND (Masse) GPIO (frei nutzbar) I2C SPI UART

Für Taster: Nimm irgendeinen grünen Pin (GPIO) + einen grauen Pin (GND). Empfehlung: GPIO 17 (Pin 11) + GND (Pin 9).

Für den OLED (I2C): 3.3V (Pin 1), GND (Pin 6), SDA (Pin 3 = GPIO 2), SCL (Pin 5 = GPIO 3).

Pin-Nummerierung verstehen

Verwirrend: der Pi kennt zwei Nummerierungen. Companion verwendet immer BCM-Nummern.

Nicht für Taster geeignet:
  • GPIO 0, 1 — reserviert (EEPROM)
  • GPIO 2, 3 — I2C (OLED)
  • GPIO 14, 15 — UART
  • GPIO 7–11 — SPI

Troubleshooting

ProblemLösung
Pin ändert sich nichtCompanion neu starten: sudo systemctl restart companion. GPIO-Modul muss (Dev) im Namen haben.
Prellt / mehrfach ausgelöstDebounce erhöhen (100–200 ms).
Wert ist immer 1Kabel vertauscht? Oder Pull-Up verkehrt → Invert anhaken.
Aux-Toggle reagiert nichtIm Trigger muss Event/Condition auf gpio:gpioX stehen (nicht RPi_GPIO:gpio_state_X). Bei „Set custom variable" den Wert als Expression speichern, und danach die ATEM-Action Aux/Output: Set source nutzen (Aux Output = z.B. Aux 1). Wenn Input rot ist, auf Variable/Expression umstellen.
OLED zeigt nichtsi2cdetect -y 1 → muss 3C zeigen. Sonst Verkabelung prüfen.
Kiosk beendenCtrl+Alt+Q
