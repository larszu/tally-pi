Was möchtest du machen?

Taster verkabeln

Ein 2-Pin-Taster zwischen einem GPIO-Pin und einem GND-Pin reicht. Der Pi aktiviert intern einen Pull-Up, d.h. Ruhe = HIGH, gedrückt = LOW.

Wichtig: Niemals 5 V an GPIO! Die Pins vertragen maximal 3.3 V.

Pinout-Übersicht findest du im Tab „📖 Hilfe".

GPIO-Modul in Companion aktivieren

  1. In Companion oben Connections öffnen.
  2. Rechts + Add connection → nach raspberry suchen → „Raspberry Pi foundation · RPi GPIO (Dev)" wählen.
  3. Namen vergeben (z.B. gpio) und speichern. Dann auf die Verbindung klicken, um sie zu konfigurieren.
  4. Scrolle zu GPIO 17 und setze:
    • ✅ Use GPIO pin
    • Set as IN/OUT = IN
    • Trigger type = FALLING
    • ✅ Enable debouncing, Debounce time = 20 ms
    • Optional: Invert values aktivieren, damit „gedrückt" = 1 ist.
  5. Speichern. Der Pin liefert jetzt die Variable $(gpio:gpio17).
Prüfen: Wechsel zum Tab ⚡ Status, drück den Taster — die Kachel GPIO 17 wird gelb und zeigt „GEDRÜCKT".

GPIO Pinout (40-Pin Header)

Der Pi 5 hat einen 40-poligen Stiftleistenanschluss. Pin 1 ist an der Ecke mit der weißen Markierung auf der Platine (Richtung SD-Karte).

Power (3.3V / 5V) GND (Masse) GPIO (frei nutzbar) I2C SPI UART

Für Taster: Nimm irgendeinen grünen Pin (GPIO) + einen grauen Pin (GND). Empfehlung: GPIO 17 (Pin 11) + GND (Pin 9).

Für den OLED (I2C): 3.3V (Pin 1), GND (Pin 6), SDA (Pin 3 = GPIO 2), SCL (Pin 5 = GPIO 3).

Nicht für Taster geeignet:
  • GPIO 0, 1 — reserviert (EEPROM)
  • GPIO 2, 3 — I2C (OLED)
  • GPIO 14, 15 — UART
  • GPIO 7–11 — SPI
